# Personal Chef AI Agent

An AI-powered cooking assistant built with LangChain and LangGraph.

## Features

- **Recipe Recommendations:** Suggests recipes based on available ingredients.
- **Web Search:** Uses Tavily to retrieve recipe information.
- **Conversational Memory:** Maintains conversation context across turns.
- **LangGraph Studio:** Supports local development and debugging.

## Tech Stack

Python · LangChain · LangGraph · OpenAI · Tavily · uv

## Getting Started

1. Clone the repository.
2. Install dependencies using `uv sync`.
3. Create a `.env` file using `.env.example` as a template.
4. Configure your OpenAI and Tavily API keys.
5. Run `uv run langgraph dev`.
